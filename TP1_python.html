Introduccion¶

En este trabajo uso curvas de Bezier para ver como aparecen las combinaciones lineales, los puntos de control y los cambios de base.

La idea general es trabajar con puntos del plano y con polinomios que funcionan como coeficientes. Segun el valor de $t$, esos coeficientes van cambiando y generan distintos puntos de la curva.

Ejercicio 1. Interpolacion lineal¶

Tengo dos puntos:

$$P_0=(1,2)$$ $$P_1=(5,4)$$

La interpolacion lineal entre ellos es:

$$L(t)=(1-t)P_0+tP_1$$

a)¶

Evaluo la funcion en algunos valores de $t$.

Para $t=0$:

$$L(0)=P_0=(1,2)$$

Para $t=1$:

$$L(1)=P_1=(5,4)$$

Para $t=0.5$ queda el punto medio entre los dos:

$$L(0.5)=(3,3)$$

b) y c)¶

Con Python calculo varios puntos de la curva y despues los grafico.

d)¶

$L(t)$ representa el segmento entre $P_0$ y $P_1$ porque cuando $t$ va de 0 a 1, el peso de $P_0$ baja y el peso de $P_1$ sube.

Entonces la funcion empieza en $P_0$, termina en $P_1$ y en el medio recorre una linea recta.

Ejercicio 2. Curva Cuadratica¶

Ahora trabajo con tres puntos de control:

$$P_0=(1,1)$$ $$P_1=(2,4)$$ $$P_2=(4,0)$$

La construccion se hace en dos pasos. Primero interpolo entre $P_0$ y $P_1$, y entre $P_1$ y $P_2$:

$$Q_0(t)=(1-t)P_0+tP_1$$ $$Q_1(t)=(1-t)P_1+tP_2$$

Despues interpolo entre esos dos puntos:

$$B(t)=(1-t)Q_0(t)+tQ_1(t)$$

a)¶

Reemplazando los puntos:

$$Q_0(t)=(1+t,1+3t)$$ $$Q_1(t)=(2+2t,4-4t)$$

b)¶

Usando esas dos expresiones:

$$B(t)=(1+2t+t^2,1+6t-7t^2)$$

c)¶

Evaluo $B(t)$ en $t=0$, $t=1$ y $t=0.5$ con el codigo.

d)¶

Como pasa con Bezier, la curva empieza en el primer punto y termina en el ultimo:

$$B(0)=P_0$$ $$B(1)=P_2$$

El punto $P_1$ no tiene por que estar sobre la curva, sino que controla la forma.

Ejercicio 3. Importancia del Orden¶

Ahora uso cuatro puntos de control:

$$P_0=(1,1)$$ $$P_1=(2,4)$$ $$P_2=(4,0)$$ $$P_3=(4,-1)$$

Como no me dan directamente la formula, uso la construccion recursiva. Es la misma idea que antes, pero con un paso mas.

Primero interpolo entre puntos consecutivos:

$$Q_0(t)=(1-t)P_0+tP_1$$ $$Q_1(t)=(1-t)P_1+tP_2$$ $$Q_2(t)=(1-t)P_2+tP_3$$

Despues interpolo entre esos resultados:

$$R_0(t)=(1-t)Q_0(t)+tQ_1(t)$$ $$R_1(t)=(1-t)Q_1(t)+tQ_2(t)$$

Y finalmente:

$$B(t)=(1-t)R_0(t)+tR_1(t)$$

a), b), c) y d)¶

Grafico la curva con el orden original y despues cambio el orden de $P_1$ y $P_2$.

La curva no queda igual. Aunque los puntos sean los mismos, cada punto ocupa un rol distinto en la construccion. Por eso el orden de los puntos de control importa.

P0 = np.array([1, 1])
P1 = np.array([2, 4])
P2 = np.array([4, 0])
P3 = np.array([4, -1])
t = np.linspace(0, 1, 100)

def interpolar(t, A, B):
    return (1 - t) * A + t * B

def calcular_curva(t, P0, P1, P2, P3):
    Q0 = interpolar(t, P0, P1)
    Q1 = interpolar(t, P1, P2)
    Q2 = interpolar(t, P2, P3)

    R0 = interpolar(t, Q0, Q1)
    R1 = interpolar(t, Q1, Q2)

    return interpolar(t, R0, R1)

Ejercicio 4. Puntos de Control y Linealidad¶

Para una curva de Bezier cubica uso cuatro puntos:

$$P_0, P_1, P_2, P_3$$

La curva se escribe como:

$$B(t)=(1-t)^3P_0+3(1-t)^2tP_1+3(1-t)t^2P_2+t^3P_3$$

a)¶

Los puntos de control son $P_0$, $P_1$, $P_2$ y $P_3$.

b)¶

En los extremos pasa esto:

$$B(0)=P_0$$ $$B(1)=P_3$$

Lo verifico con una funcion general de Bezier cubica.

c)¶

$P_1$ y $P_2$ no tienen por que estar sobre la curva. Sirven para controlar la forma.

$P_1$ influye en como sale la curva desde $P_0$, y $P_2$ influye en como llega hacia $P_3$.

d)¶

La dependencia respecto de los puntos de control es lineal porque la curva es una suma de esos puntos multiplicados por coeficientes que dependen de $t$.

Los puntos no se multiplican entre si ni aparecen elevados a potencias.

def B_cubica(t, P0, P1, P2, P3):
    return (1 - t)**3 * P0 + 3 * (1 - t)**2 * t * P1 + 3 * (1 - t) * t**2 * P2 + t**3 * P3

Ejercicio 5. Polinomios de Bernstein¶

Trabajo con los cuatro polinomios de Bernstein cubicos y los escribo en la base monomial.

a)¶

Expando cada uno:

$$b_0(t)=(1-t)^3=1-3t+3t^2-t^3$$ $$b_1(t)=3(1-t)^2t=3t-6t^2+3t^3$$ $$b_2(t)=3(1-t)t^2=3t^2-3t^3$$ $$b_3(t)=t^3$$

b)¶

Cada polinomio lo guardo como un vector de coeficientes en el orden:

$$[1,t,t^2,t^3]$$

Entonces:

$$b_0=(1,-3,3,-1)$$ $$b_1=(0,3,-6,3)$$ $$b_2=(0,0,3,-3)$$ $$b_3=(0,0,0,1)$$

c) y d)¶

Armo una matriz $A$ usando esos vectores como columnas. Cada columna representa uno de los polinomios de Bernstein escrito en la base monomial.

e)¶

La matriz es triangular inferior, entonces el determinante es el producto de la diagonal:

$$\det(A)=1\cdot3\cdot3\cdot1=9$$

Como el determinante es distinto de cero, $A$ es invertible.

f)¶

Como $A$ es invertible, sus columnas son linealmente independientes.

Entonces los polinomios de Bernstein son linealmente independientes. Ademas, como son cuatro polinomios linealmente independientes en $P_3$, forman una base de $P_3$.

Ejercicio 6. La Matriz de Bezier¶

La curva cubica tambien se puede escribir en forma matricial.

Si uso:

$$T=(1,t,t^2,t^3)$$

entonces los coeficientes de Bernstein se recuperan haciendo:

$$T M$$

La matriz $M$ tiene como columnas los coeficientes de los polinomios de Bernstein escritos en la base monomial:

$$M=\begin{pmatrix}1&0&0&0\\-3&3&0&0\\3&-6&3&0\\-1&3&-3&1\end{pmatrix}$$

a) y b)¶

Con esa matriz puedo representar la curva usando los puntos de control y el vector $T$.

c)¶

Verifico el producto matricial con $t=0.5$. El resultado tiene que coincidir con los coeficientes de Bernstein evaluados en ese valor.

d)¶

Si los puntos estan en $R^2$, entonces:

$$[P_0\ P_1\ P_2\ P_3] \in R^{2\times4}$$ $$M \in R^{4\times4}$$ $$[1,t,t^2,t^3]^T \in R^{4\times1}$$

El resultado es un punto del plano, o sea un vector de dimension $2\times1$.

En Python guardo los puntos como filas, por eso uso $T M P$ y obtengo directamente un vector de dimension 2.

Ejercicio 8. Polinomios de Bernstein¶

Uso los mismos polinomios que venimos usando para la curva cubica:

$$b_0(t)=(1-t)^3$$ $$b_1(t)=3(1-t)^2t$$ $$b_2(t)=3(1-t)t^2$$ $$b_3(t)=t^3$$

a)¶

La curva se escribe como una combinacion lineal de los puntos de control:

$$B(t)=b_0(t)P_0+b_1(t)P_1+b_2(t)P_2+b_3(t)P_3$$

Reemplazando los polinomios queda:

$$B(t)=(1-t)^3P_0+3(1-t)^2tP_1+3(1-t)t^2P_2+t^3P_3$$

b)¶

Quiero ver que los coeficientes suman 1. Entonces sumo:

$$(1-t)^3+3(1-t)^2t+3(1-t)t^2+t^3$$

Expando cada termino:

$$(1-3t+3t^2-t^3)+(3t-6t^2+3t^3)+(3t^2-3t^3)+t^3$$

Ahora agrupo por potencias de $t$:

$$1+(-3t+3t)+(3t^2-6t^2+3t^2)+(-t^3+3t^3-3t^3+t^3)=1$$

Entonces:

$$b_0(t)+b_1(t)+b_2(t)+b_3(t)=1$$

Esto vale para todo $t$.

c)¶

Evaluo los polinomios en los extremos.

Para $t=0$:

$$b_0(0)=1, \quad b_1(0)=0, \quad b_2(0)=0, \quad b_3(0)=0$$

Entonces en $t=0$ los coeficientes son:

$$(1,0,0,0)$$

Para $t=1$:

$$b_0(1)=0, \quad b_1(1)=0, \quad b_2(1)=0, \quad b_3(1)=1$$

Entonces en $t=1$ los coeficientes son:

$$(0,0,0,1)$$

d)¶

Como la curva es:

$$B(t)=b_0(t)P_0+b_1(t)P_1+b_2(t)P_2+b_3(t)P_3$$

en $t=0$ queda:

$$B(0)=1P_0+0P_1+0P_2+0P_3=P_0$$

y en $t=1$ queda:

$$B(1)=0P_0+0P_1+0P_2+1P_3=P_3$$

Por eso la curva empieza en $P_0$ y termina en $P_3$. Los puntos del medio no son necesariamente puntos por donde pasa la curva, sino que controlan la forma.

Ejercicio 9. Independencia lineal¶

Quiero ver si los polinomios de Bernstein cubicos son linealmente independientes.

El conjunto es:

$$B=\{(1-t)^3,3(1-t)^2t,3(1-t)t^2,t^3\}$$

a)¶

Para estudiar la independencia lineal planteo una combinacion lineal igualada a cero:

$$\alpha(1-t)^3+\beta\,3(1-t)^2t+\gamma\,3(1-t)t^2+\delta t^3=0$$

La idea es ver si la unica forma de que eso de cero es que todos los coeficientes sean cero.

b)¶

Expando cada polinomio en la base monomial:

$$(1-t)^3=1-3t+3t^2-t^3$$ $$3(1-t)^2t=3t-6t^2+3t^3$$ $$3(1-t)t^2=3t^2-3t^3$$ $$t^3=t^3$$

Reemplazo en la combinacion lineal:

$$\alpha(1-3t+3t^2-t^3)+\beta(3t-6t^2+3t^3)+\gamma(3t^2-3t^3)+\delta t^3=0$$

Ahora agrupo por potencias de $t$.

Termino independiente:

$$\alpha$$

Coeficiente de $t$:

$$-3\alpha+3\beta$$

Coeficiente de $t^2$:

$$3\alpha-6\beta+3\gamma$$

Coeficiente de $t^3$:

$$-\alpha+3\beta-3\gamma+\delta$$

Como todo el polinomio tiene que ser cero, cada coeficiente tiene que ser cero:

$$\alpha=0$$ $$-3\alpha+3\beta=0$$ $$3\alpha-6\beta+3\gamma=0$$ $$-\alpha+3\beta-3\gamma+\delta=0$$

c)¶

De la primera ecuacion sale directamente:

$$\alpha=0$$

Reemplazo en la segunda:

$$3\beta=0$$

Entonces:

$$\beta=0$$

Reemplazo en la tercera:

$$3\gamma=0$$

Entonces:

$$\gamma=0$$

Y en la ultima queda:

$$\delta=0$$

Por lo tanto:

$$\alpha=\beta=\gamma=\delta=0$$

d)¶

La unica combinacion lineal que da el polinomio cero es la trivial.

Entonces los polinomios de Bernstein cubicos son linealmente independientes.

Ademas, como son cuatro polinomios linealmente independientes en $P_3$, forman una base de $P_3$.

Ejercicio 10. Cambio entre la base monomial y la base de Bernstein¶

En este ejercicio comparo dos formas de escribir los polinomios de $P_3$.

La base monomial es:

$$M=\{1,t,t^2,t^3\}$$

Y la base de Bernstein cubica es:

$$B=\{(1-t)^3,3(1-t)^2t,3(1-t)t^2,t^3\}$$

a)¶

Para armar la matriz de cambio de base, escribo cada polinomio de Bernstein en la base monomial.

Primero los expando:

$$(1-t)^3=1-3t+3t^2-t^3$$ $$3(1-t)^2t=3t-6t^2+3t^3$$ $$3(1-t)t^2=3t^2-3t^3$$ $$t^3=t^3$$

Entonces sus coordenadas en la base $\{1,t,t^2,t^3\}$ son:

$$(1,-3,3,-1)$$ $$(0,3,-6,3)$$ $$(0,0,3,-3)$$ $$(0,0,0,1)$$

Uso esos vectores como columnas y queda la matriz:

$$A=\begin{pmatrix}1&0&0&0\\-3&3&0&0\\3&-6&3&0\\-1&3&-3&1\end{pmatrix}$$

Esta matriz lleva coordenadas desde la base de Bernstein hacia la base monomial.

b)¶

La matriz es triangular inferior. Entonces el determinante es el producto de los elementos de la diagonal:

$$\det(A)=1\cdot3\cdot3\cdot1=9$$

c)¶

Como el determinante es distinto de cero:

$$\det(A)\neq0$$

la matriz es invertible.

d)¶

Que la matriz sea invertible significa que puedo pasar de una base a la otra sin perder informacion.

Entonces la base monomial y la base de Bernstein describen el mismo espacio $P_3$. Cualquier polinomio de grado menor o igual a 3 se puede escribir en cualquiera de las dos bases.

Ejercicio 14. Derivadas y continuidad de curvas compuestas¶

Tengo dos curvas de Bezier cubicas consecutivas.

La primera curva $B_1(t)$ tiene puntos de control:

$$P_0,P_1,P_2,P_3$$

La segunda curva $B_2(t)$ tiene puntos de control:

$$P_3,P_4,P_5,P_6$$

Las dos curvas se unen en $P_3$.

a)¶

Para que la curva compuesta tenga continuidad $C^1$ en $P_3$, las derivadas tienen que coincidir en el punto de union:

$$B_1'(1)=B_2'(0)$$

Para una curva de Bezier cubica, las derivadas en los extremos son:

$$B_1'(1)=3(P_3-P_2)$$

$$B_2'(0)=3(P_4-P_3)$$

Entonces la condicion queda:

$$3(P_3-P_2)=3(P_4-P_3)$$

Cancelo el 3:

$$P_3-P_2=P_4-P_3$$

Despejando:

$$P_4=2P_3-P_2$$

Esto significa que $P_2$, $P_3$ y $P_4$ tienen que estar alineados, y ademas $P_3$ queda en el medio de $P_2$ y $P_4$.

b)¶

Si pasa que:

$$B_1'(1)=B_2'(0)=0$$

entonces la curva llega a $P_3$ con velocidad cero y sale de $P_3$ tambien con velocidad cero.

En ese caso $P_3$ es un punto estacionario. La curva sigue siendo continua, pero se detiene en el punto de union.

c)¶

Para continuidad $C^2$ tambien tienen que coincidir las segundas derivadas:

$$B_1''(1)=B_2''(0)$$

Para una curva cubica de Bezier:

$$B_1''(1)=6(P_3-2P_2+P_1)$$

$$B_2''(0)=6(P_5-2P_4+P_3)$$

Igualo:

$$6(P_3-2P_2+P_1)=6(P_5-2P_4+P_3)$$

Cancelo el 6:

$$P_3-2P_2+P_1=P_5-2P_4+P_3$$

Despejo $P_5$:

$$P_5=P_1-2P_2+2P_4$$

Pero por la continuidad $C^1$ ya tenia:

$$P_4=2P_3-P_2$$

Entonces reemplazo:

$$P_5=P_1-2P_2+2(2P_3-P_2)$$

$$P_5=P_1-4P_2+4P_3$$

Por lo tanto $P_5$ queda completamente determinado por $P_1$, $P_2$ y $P_3$.

Ejercicio 15: Competencia de Curvas de Bézier¶

Justificación del procedimiento para diseñar la trayectoria¶

El objetivo del problema es construir una curva de Bézier cúbica que conecte la casa de Roberto (A=(0,0)) con la casa de Damián (D=(10,5)), evitando todos los obstáculos del mapa y procurando que la trayectoria tenga la menor longitud posible. Para ello se utilizan cuatro puntos de control:

[ P_0,; P_1,; P_2,; P_3 ]

donde (P_0=A) y (P_3=D).

1. Curva de Bézier cúbica¶

La curva utilizada está definida por la expresión

[ B(t) = (1-t)^3 P_0 + 3(1-t)^2 t P_1 + 3(1-t)t^2 P_2 + t^3 P_3, \quad t\in[0,1] ]

Esta ecuación es una combinación lineal de los puntos de control, ponderada por los polinomios de Bernstein.
Desde el punto de vista del álgebra lineal, cada punto de la curva es una combinación convexa de (P_0,P_1,P_2,P_3).

2. Propiedad de la envolvente convexa¶

Una propiedad fundamental de las curvas de Bézier es que toda la curva queda contenida dentro del casco convexo de sus puntos de control.

Esto implica que:

  • la trayectoria siempre permanece dentro del polígono formado por
    (P_0, P_1, P_2, P_3)
  • si ubicamos este polígono de forma que rodeé los obstáculos, entonces la curva también los evitará.

Por esta razón los puntos (P_1) y (P_2) se eligieron de modo que el polígono de control pase por la zona superior del mapa, donde hay más espacio libre.

3. Tangentes en los extremos¶

Otra propiedad importante de las curvas de Bézier cúbicas es que la dirección de la tangente en los extremos depende de los vectores

[ B'(0) = 3(P_1 - P_0) ]

[ B'(1) = 3(P_3 - P_2) ]

Esto significa que:

  • el vector (P_1 - P_0) determina la dirección inicial del movimiento
  • el vector (P_3 - P_2) determina cómo llega la curva al punto final

En el diseño de la trayectoria:

  • (P_1) se posiciona por encima de (P_0) para que la curva suba rápidamente y evite el pozo cercano.
  • (P_2) se ubica antes del destino pero también elevado, lo que genera una llegada suave al punto (D) sin pasar por la casa abandonada ni por los arbustos.

4. Uso de combinaciones lineales para posicionar los puntos¶

Los puntos (P_1) y (P_2) se ajustaron utilizando combinaciones lineales y una búsqueda numérica para encontrar posiciones que cumplan simultáneamente:

  1. evitar la intersección con los obstáculos,
  2. mantener la trayectoria lo más recta posible,
  3. minimizar la longitud total de la curva.

En términos geométricos, el algoritmo genera distintas configuraciones de (P_1) y (P_2) dentro de la región libre y calcula la longitud de la curva resultante.
Entre todas las trayectorias válidas se selecciona la que posee la menor longitud.

5. Conclusión¶

El método utilizado combina propiedades geométricas de las curvas de Bézier con conceptos de álgebra lineal:

  • uso de combinaciones convexas para definir la curva,
  • aprovechamiento de la envolvente convexa para garantizar que la trayectoria no atraviese obstáculos,
  • control de la dirección de las tangentes mediante los vectores (P_1-P_0) y (P_3-P_2).

De esta manera se obtiene una trayectoria suave, continua y válida, que conecta los puntos (A) y (D) evitando los obstáculos y manteniendo una longitud cercana a la mínima posible.

def bezier3(P0,P1,P2,P3,n=200):

    t=np.linspace(0,1,n)

    B=(np.outer((1-t)**3,P0)
      +np.outer(3*(1-t)**2*t,P1)
      +np.outer(3*(1-t)*t**2,P2)
      +np.outer(t**3,P3))

    return B


def longitud(curva):

    d=np.diff(curva,axis=0)
    return np.sum(np.sqrt((d**2).sum(axis=1)))

def punto_en_poligono(p,poly):

    x,y=p
    inside=False

    for i in range(len(poly)):

        x1,y1=poly[i]
        x2,y2=poly[(i+1)%len(poly)]

        if ((y1>y)!=(y2>y)) and (x<(x2-x1)*(y-y1)/(y2-y1)+x1):
            inside=not inside

    return inside


def colision(p,obstaculos):

    for obs in obstaculos:

        if obs["tipo"]=="circulo":

            if np.linalg.norm(p-obs["centro"])<=obs["radio"]:
                return True

        elif obs["tipo"]=="rectangulo":

            if obs["xmin"]<=p[0]<=obs["xmax"] and obs["ymin"]<=p[1]<=obs["ymax"]:
                return True

        elif obs["tipo"]=="poligono":

            if punto_en_poligono(p,obs["verts"]):
                return True

    return False
